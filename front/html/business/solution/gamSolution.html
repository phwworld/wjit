내부회계 및 권한정비 솔루션

GAM SOLUTION

GAM(Global Audit Management)는 내부 회계관리 제도의 실질적 운용을 위한 능동적이고 위험관리 수준을 향상 시킬 수 있는 통제 시스템입니다. 표준화된 권한 점검 프로세스 기반으로 안정적인 권한 운영 관리와 실시간 모니터링 정보를 제공합니다.

GAM Solution이란?

글로벌 감사·내부통제·권한 관리를 통합 지원하는 플랫폼입니다. SAP뿐 아니라 Non-SAP 시스템까지 아우르며, IAM·권한 관리·SoD 분리 등 핵심 기능을 제공합니다. 기업은 내부회계 감사 대응, 규제 준수, 리스크 감소, 운영 효율성을 동시에 확보할 수 있습니다.

내부회계 및 권한 정비를 위한 시스템

웅진의 Global Audit Management Solution은 내부 회계관리 제도의 실질적 운용을 위한 능동적 시스템이며, 위험관리 수준을 향상 시킬 수 있는 통제 시스템입니다. 내부회계관리, IT감사관리, 권한관리를 표준화된 프로세스로 운영 가능하며 실시간 모니터링을 통해 즉각적인 인사이트 정보를 제공합니다.

솔루션별 주요 장점 및 차별점

GAM SOLUTION은 SAP에 엔진을 탑재하는 embedded 구조로, 별도 서버와 추가 라이선스 없이 내부회계·IT감사·권한관리를 자동화합니다. ICS·ITGC·AM을 하나의 플랫폼에서 연계해 완전성·적시성·운영 효율을 동시에 확보합니다.

  • 평가 자동화 가능

  • 모집단 완전성·데이터 무결성 확보, SR 및 지급 연동 방식 증빙 자동화
  • Excel 일괄 Upload
  • 효율성 ↑ 60%, 감사인 대응력 ↑ 50%, 업무부담 ↓ 60%, 운영비용 ↓ 50%

시스템 구현 방법론

GAM SOLUTION은 내부회계(ICS), IT감사관리(ITGC), 권한정비/관리(AM), 모니터링을 표준 프로세스로 구현합니다. SAP 데이터와 직접 연동해 완전성과 적시성을 확보하고, 평가부터 증적·보고까지 자동화합니다.

1. 내부회계(ICS) 솔루션

SAP 기반으로는 유일하게 RCM 통제 모집단 자동 추출 기능을 보유하고 있습니다. 신속한 자동 추출방식을 통해 완전성과 적시성을 확보하고 추출된 모집단의 통제 주기 및 샘플 수에 맞춘 자동 샘플링 기능을 지원합니다.

01. 평가 주기

  • Scoping
  • 재무제표 자동연동
  • 자동 핵심통제

02. 자동 추출

  • 모집단 자동 추출 완전성 / 무결성 보장
  • 모집단 80% 이상 자동화 가능

03. 자동 샘플링

  • 모범규준 적용샘플 (100%)

04. 자동 증빙

  • 요청 / 결재 연동 증빙 (60%)

05. 평가 수행

  • 증빙 결과 연동 평가 자동 수행 (50%)

06. 리스크 도출

  • 중요 리스크 자동 분석
  • 유형별 미비점 자동 분석 (60%)

07. 미비점 보완

  • 중요 취약점 해결방안
  • 리스크 관리 솔루션 연계
시스템 자동화 수준 대폭 향상
완전성/무결성 80% 확보
운영 효율성 60% 증가
감사인 대응력 50% 증가
업무 부담 60% 감소
운영 비용 50% 감소
2. IT감사관리(ITGC) 솔루션

접근·변경·운영·권한 통제 증적을 실시간 수집하고, 정기보고까지 자동화하여 IT 일반통제 투입 인력과 감사 대응 부담을 줄입니다.

접근 통제

  • ID관리 : 접근기록, 패스워드 변경일
  • 로그인관리 : 장기 미접속자, 퇴직자 접근
  • 사용자 변경 : 소속 변경, 사용자 변경

변경 통제

  • 프로그램 변경 : CTS, ITS, 전자결재 증빙
  • 데이터 변경 : 데이터 변경 내용 증빙
  • 디버깅 변경 : 디버깅 변경 내용 증빙

운영 통제

  • 런타임 오류 : 조치사항 관리
  • 배치잡 등록 : 배치잡 등록 증빙
  • 배치잡 관리 : 수행관리, 실패에 대한 조치

권한 통제

  • 권한 증빙 : 권한변경 증빙
  • 전표생성 증빙 : 비권한자 전표 증빙

3. 권한정비/관리(AM) 솔루션

AS-IS 권한을 자동 분석하고 TO-BE 기준의 Role을 재생성·회수하여, 권한 담당자 의존 수작업을 솔루션 기반 자동 부여로 전환합니다.

권한정비

01. AS-IS 권한 자동분석

  • 사용자별 역할/권한/권한 오브젝트 자동 분석 결과 도출

02. TO-BE 기준 정립 권한 재정의

  • 사용자별 직무권한/분리 Matrix 정의 (Standard Matrix 기본 제공)

03. 권한 자동 역할 재생성

  • 사용자별 Matrix 기준 반영 역할 자동 재생성

04. 권한 재설정

  • 부적합권한 회수제안 자동 권한 일괄회수
권한운영

AS-IS

  • 전자결재 후 담당자 승인, 수작업 권한 부여
  • 권한부여/회수 요청서 상신
  • 권한 담당자 승인 및 BC 역할 생성/사용자 매핑
  • 공유 역할 선정, 수작업 권한설정
  • 권한 담당자 의존으로 부적합 권한 발생 가능

TO-BE

  • AM 전자결재 승인 후 자동권한 부여
  • 권한부여/회수 요청서 상신
  • 관련 주무부서 검토 → 권한 담당자 승인
  • 솔루션 조건 부합 역할 선정, 자동 권한 설정
  • 권한 상시 모니터링 및 부적합 권한 알림
4. 모니터링

실시간 모니터링 정보와 경영진을 위한 Dashboard를 제공합니다. 통제별 현황 지표 확인 기능 및 감사 시, 증적 관리 및 시각적 자료를 한 화면에서 편리하게 파악할 수 있습니다.

실시간 권한 모니터링

실시간 ITGC 모니터링

  • 통제 카테고리별 현황 확인
  • 데이터 수집 현황 및 조치 알림

FAQ가장 자주 묻는 질문과 답변을 모았습니다.
Q1. GAM Solution은 어떤 솔루션인가요?
GAM Solution은 글로벌 감사·내부 통제·권한 관리를 통합 지원하는 내부회계관리 솔루션입니다. SAP뿐 아니라 Non-SAP 시스템까지 통합하여 계정과 권한을 중앙에서 관리하며, 내부회계 감사 대응과 컴플라이언스를 강화합니다.
Q2. 기업이 GAM Solution을 도입해야 하는 이유는 무엇인가요?
권한 남용과 내부 통제 부재는 기업 리스크와 감사 실패로 이어질 수 있습니다. GAM Solution은 권한 자동화, SoD(업무분리), FUE 최적화를 통해 리스크를 줄이고 규제 대응과 투명한 경영을 보장합니다.
Q3. GAM Solution은 어떤 기능을 제공하나요?
IAM 기반 계정 관리, Role·권한 자동부여, 권한점검, 운영보고서, 전자결재 연동 승인·회수, SoD/FUE 관리, 로그·변경 이력 추출 등 권한 관리 전 과정의 자동화 기능을 제공합니다.
Q4. 어떤 산업에서 GAM Solution이 필요한가요?
금융, 제조, 공공, 글로벌 기업 등 내부회계 관리제도와 규제 준수가 중요한 산업에서 특히 필요합니다. SAP ERP는 타 ERP와도 연동되어 다양한 기업 환경에 적용됩니다.
Q5. GAM Solution을 도입하면 어떤 효과를 얻을 수 있나요?
권한 정비 비용 60% 절감, 기간 55% 단축, 부적합 권한률 0% 달성 등 검증된 효과가 있습니다. 또한 감사 대응력 강화, 내부 통제 표준화, 운영 효율 향상으로 리스크 감소와 경영 투명성 제고에 기여합니다.
